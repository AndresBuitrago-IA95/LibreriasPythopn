import numpy as np # ─── CREAR ARRAYS ───────────────────────────────── # 🟢 np.array() convierte una lista en array NumPy pqrs_mensuales = np.array([412, 438, 465, 420, 480, 392, 455, 471, 448, 436]) # PQRS recibidas en Alcaldía de (ene–oct) # ─── ESTADÍSTICAS INSTANTÁNEAS ──────────────────── print(f'Media: {np.mean(pqrs_mensuales):.1f}') print(f'Mediana: {np.median(pqrs_mensuales):.1f}') print(f'Std: {np.std(pqrs_mensuales):.1f}') print(f'Min/Max: {np.min(pqrs_mensuales)} / {np.max(pqrs_mensuales)}') # ─── OPERACIONES VECTORIZADAS ───────────────────── # 🟢 En Python normal necesitarías un for loop # 🟢 NumPy lo hace a TODOS los elementos a la vez meta = 450 diferencia = pqrs_mensuales - meta # [412-450, 438-450, 465-450, ...] = [-38, -12, 15, ...] meses_excedidos = np.sum(pqrs_mensuales > meta) print(f'Meses sobre la meta: {meses_excedidos}')

📋 PANDAS AVANZADO

GroupBy · Merge · Apply

Las 3 operaciones más poderosas para cruzar datos de secretarías

pandas_avanzado.py
# ─── GROUPBY ────────────────────────────────────── # 🟢 .groupby() agrupa filas por categoría resumen = df_pqrs.groupby('secretaria').agg({ 'pqrs_mes': ['sum', 'mean'], 'dias_resp': 'mean', 'satisf': 'max' }) # ─── APPLY CON FUNCIÓN PROPIA ───────────────────── # 🟢 .apply() aplica una función a cada fila def semaforo(dias): if dias <= 5: return '🟢 OK' elif dias <= 10: return '🟡 Riesgo' else: return '🔴 Crítico' df_pqrs['estado'] = df_pqrs['dias_resp'].apply(semaforo) # ─── MERGE (cruzar 2 tablas) ────────────────────── # 🟢 Como un JOIN en SQL o BUSCARV en Excel df_presupuesto = pd.DataFrame({ 'secretaria': ['Gobierno','Hacienda','Salud'], 'presupuesto': [500, 800, 1200] }) df_completo = pd.merge(df_pqrs, df_presupuesto, on='secretaria', how='left')

🔀 .groupby() + .agg()

Como una tabla dinámica de Excel. Agrupa por secretaría y calcula: suma, promedio, máximo, mínimo — todo a la vez en 3 líneas.

df.groupby('zona')['recaudo'].mean()

⚡ .apply(función)

Aplica una función personalizada a cada valor. Perfecto para crear semáforos, clasificar secretarías o calcular indicadores complejos.

df['estado'] = df['dias'].apply(semaforo)

🔗 pd.merge()

Cruza dos tablas por una columna común. Como BUSCARV en Excel pero más potente: maneja millones de filas sin problemas.

pd.merge(df1, df2, on='secretaria')

📊 .describe() rápido

En una línea: count, mean, std, min, Q1, Q2, Q3, max. Primera función a ejecutar al analizar cualquier dataset de la Alcaldía.

df_pqrs.describe()

🔬 SCIPY

SciPy — Estadística Avanzada

Pruebas estadísticas para tomar decisiones basadas en datos · ¿La mejora es real o casualidad?

scipy_estadistica.py
from scipy import stats import numpy as np # ─── MODA ───────────────────────────────────────── # 🟢 Para datos numéricos discretos calificaciones = [4,5,4,4,5,3,4,5,4,3] m = stats.mode(calificaciones, keepdims=True) print(f'Moda: {m.mode[0]} estrellas') # ─── CORRELACIÓN DE PEARSON ─────────────────────── # 🟢 r y p-valor: ¿están relacionadas las variables? inversion = [150, 200, 280, 180, 320] satisfaccion = [62, 70, 82, 65, 88] r, p = stats.pearsonr(inversion, satisfaccion) print(f'r={r:.3f}, p={p:.4f}') # Si p < 0.05 → correlación estadísticamente real # ─── PRUEBA t DE HIPÓTESIS ─────────────────────── # ¿M365 Copilot mejoró el tiempo de respuesta PQRS? np.random.seed(42) antes = np.random.normal(8.0, 2.5, 30) despues = np.random.normal(5.5, 1.8, 30) t, p = stats.ttest_ind(antes, despues) print(f'p-valor: {p:.6f}') # p < 0.05 → la mejora es REAL, no casualidad

🎯 stats.mode() — Moda

Para encontrar el valor más frecuente en datos numéricos. Úsalo para calificaciones de satisfacción (1–5 estrellas) o tipos de trámite codificados.

stats.mode(datos, keepdims=True)

🔗 stats.pearsonr() — Correlación

Mide si dos variables están relacionadas. Devuelve r (fuerza: -1 a +1) y p (significancia: <0.05 = real).

r > 0.7 → fuerte r 0.4-0.7 → moderado r < 0.4 → débil

🔬 stats.ttest_ind() — Prueba t

Compara dos grupos para saber si la diferencia es estadísticamente real. p < 0.05 → la mejora no es casualidad → es una decisión válida.

p < 0.05 ✅ real p ≥ 0.05 ❌ casualidad

📊 Matplotlib vs ✨ Plotly

¿Cuándo usar cada una? Ambas son necesarias — tienen propósitos diferentes

📊 MATPLOTLIB — Úsalo cuando...

✅

Necesitas exportar a PDF o PNG para informes oficiales, actas o presentaciones del Concejo Municipal

✅

Quieres gráficos de alta resolución con dpi=300 para impresión de calidad

✅

Necesitas personalización total: fuentes, colores específicos, posición exacta de elementos

✅

Trabajas en entornos sin internet o sistemas sin JavaScript

✅

El gráfico va dentro de un documento Word o PowerPoint generado con Python

✨ PLOTLY — Úsalo cuando...

✅

Necesitas un dashboard interactivo que la Alcaldía actualizará periódicamente con datos de gestión

✅

Quieres que el Alcalde o los Secretarios puedan explorar los datos por sí mismos haciendo hover y zoom

✅

El análisis se va a publicar en la web o compartir como enlace entre funcionarios

✅

Tienes múltiples dimensiones de datos (color + tamaño + forma + animación) que mostrar a la vez

✅

Quieres que los ciudadanos puedan interactuar con los datos del portal de transparencia de

💡 Tips para el Bootcamp

Errores comunes y cómo resolverlos en Google Colab

⚡ ModuleNotFoundError: plotly

Escribe !pip install plotly en una celda y ejecuta. El ! es necesario para instalar desde Colab. Reinicia el kernel después.

📋 KeyError en Pandas

df['nombre_columna'] — el nombre de columna debe coincidir exactamente (mayúsculas, tildes, espacios). Usa df.columns para ver los nombres exactos.

📊 Gráfico no aparece

Agrega plt.show() al final de cada bloque de gráfico. En Jupyter/Colab también puedes agregar %matplotlib inline al inicio de la sesión.

✨ Plotly no muestra nada

Agrega import plotly.io as pio; pio.renderers.default = "colab" al inicio. Esto configura Plotly para mostrarse correctamente en Google Colab.

🔬 SciPy keepdims warning

Usa siempre scipy.stats.mode(datos, keepdims=True). Sin keepdims=True da advertencias en versiones recientes. Accede al resultado con resultado.mode[0].

🔢 NumPy vs lista Python

np.mean([1,2,3]) funciona igual que np.mean(np.array([1,2,3])). NumPy acepta listas directamente, pero los arrays son más rápidos para grandes volúmenes de datos.
